Saily 是 Nord Security（NordVPN 母公司）开发的 eSIM 服务。特点是国内身份证 KYC、美国实体号码（非 VoIP）、月租低（首月 0.6 刀，之后 0.99 刀）。本文记录关键属性与踩坑点，不附推广码。

## 开卡流程

1. Google Play / Apple Store 下载 Saily。
2. 抵用金入口输入礼券码（或两账号互邀邀请码），获取首月抵用金。
3. 首页 → 探索电话号码 → 获取电话号码 → 美国号码 → 中国使用 → 支付 → 实名认证 → eSIM 下载扫码。

号码归属地按购买时的登录 IP 分发，例如 Texas 地址分发 (940) 区号。

## 号码属性验证

用 [phonevalidator.com](https://phonevalidator.com/) 反查号码是否为 Cell / Landline / VoIP。Saily 分发为实体号码（非 VoIP），这是它的主要卖点。

## 重要限制

- **抵用金不可抵月租**（官方客服明确）。抵用金只用于首月促销，月租仍需另行支付。
- **只有号码，不含流量**。收发短信需购买套餐；与带 1GB 流量的"红包卡"相比功能性更窄，但保号成本极低。
- 激活后 APP 可能仍显示未激活：有信号后多刷新、重进几次即可正常。
- 有用户反馈注册不了 ChatGPT/OpenAI——此类验证取决于目标平台风控对各号段的实时判定，与"实体/虚拟"标称不完全等价。

## 与同类方案对比

| 项目       | Saily eSIM     | 红包卡类        |
| ---------- | -------------- | --------------- |
| 月租       | 0.99 刀        | 类似量级        |
| 流量       | 无（需购套餐） | 常含 1GB        |
| 号码类型   | 美国实体非 VoIP| 取决于发行方    |
| 使用场景   | 纯保号 / 收码   | 出门导航听歌收机况 |

适合只需要一个稳定美国号码长期保号收码、不需要流量的场景。出门开车导航听歌的场景，带流量的红包卡更实用。
